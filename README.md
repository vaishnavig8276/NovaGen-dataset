
# 🚀 NovaGen Research Labs

Welcome to the **NovaGen** repository. This project contains structured tabular data and machine learning workflows designed for robust classification tasks. It provides an excellent foundation for building baseline models and experimenting with various algorithms, from simple linear models to complex ensemble architectures.

## ✨ Key Features

*   **Tabular Classification Data:** Clean, structured dataset (`novagen_dataset.csv`) prepared for target-based prediction tasks.
*   **Ensemble-Ready Pipeline:** Optimized for testing and evaluating `scikit-learn` models including Random Forest, Gradient Boosting, and Voting Classifiers.
*   **Baseline Benchmarking:** Includes a complete Jupyter Notebook (`novagen.ipynb`) for rapid baseline model creation, feature scaling, and performance evaluation.
